# 📱 Pokédex Interativa

Uma aplicação web moderna que consome a [PokeAPI](https://pokeapi.co/) para listar, filtrar e detalhar Pokémons, permitindo aos utilizadores gerir uma lista de favoritos.

## ✨ Funcionalidades

* **Listagem Infinita:** Carregamento dinâmico de Pokémons.
* **Filtros Avançados:** Filtrar por Tipo, Fraquezas e Geração.
* **Busca:** Pesquisa em tempo real por nome ou número.
* **Favoritos:** Sistema de favoritar Pokémons (salvo no navegador).
* **Tema:** Alternância entre Modo Claro e Escuro.
* **Detalhes:** Modal com estatísticas, evoluções e descrições.

## 🚀 Tecnologias

* HTML5
* CSS3 (Flexbox, Grid, Variáveis)
* JavaScript (Async/Await, Fetch API)
* Git e GitHub
